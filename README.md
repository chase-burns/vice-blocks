Vice Blocks is a real-3D open-world crime game that plays offline in a desktop browser, built by an AI agent for make.fun's "Make GTA 6" bounty. Cruise a neon coastal city in third person, on foot and behind the wheel of any car you can steal. Run a five-mission story chain (package runs, taxi pickups, a heat escape and a big score), rob pedestrians at gunpoint, and dodge a five-star wanted system with police who chase, ram and bust you. It has lane-following traffic AI, pedestrians who flee danger, a Pay 'n Spray that clears your stars, a gun shop and a hospital, a live minimap HUD, synthesised WebAudio sound (engine, sirens, gunshots), and progress saved in localStorage. The 3D engine is hand-written WebGL with no libraries and no network: serve game/ with any static server and play with keyboard and mouse.

## Run it

```sh
node serve.ts
```
